# Change Log

## [Unreleased]

- Added top-of-file theme label comments to all theme JSON files.
- Updated project docs with a full list of included themes.
- Added missing theme schema references to improve JSON tooling support.
- Added new theme `argprocolor-midnight-neon-aura` as an enhanced glow variant while preserving the original `argprocolor-midnight-glow`.
- Added new light theme `argprocolor-daylight-sleek-mono` inspired by a monochromatic SlickEdit style with low eye strain.
- Added new light theme `argprocolor-daylight-prism` as a refined, high-clarity evolution of the original daylight palette.
